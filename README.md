## What is Astakos?

Astakos is a **self-hosted AI agent** you run on your own machine. It connects to Telegram and a Web UI, understands your habits, remembers things about you, and proactively reaches out when it thinks you need it.

It's not a chatbot wrapper. It's a full multi-agent system built on LangGraph with:
- A **Supervisor** that routes your requests to the right specialist agent
- A **persistent memory layer** (ChromaDB + SQLite) that survives restarts
- A **routine learning engine** that watches your daily patterns and learns from them
- A **nightly analytics engine** that uses an LLM to detect recurring activities from your chat history
- **Proactive messages** written by the LLM — not dry templates, but natural ones like a friend who remembers

## 🏗 Architecture

```
   Telegram Bot          Web UI             CLI
   [channel=telegram]  [channel=web]   [channel=terminal]
         │                  │                  │
         └──────────────────┼──────────────────┘
                            ▼
                    ┌─────────────┐
                    │  Supervisor │  ← Routes to the right agent
                    └──────┬──────┘
                           │
          ┌────────────────▼────────────────────────────────┐
          │  Chat · Home · Web · Tech · Git · Mail · Dev     │
          └────────────────┬────────────────────────────────┘
                           │
               ┌───────────▼──────┐    ┌───────────────────────────────┐
               │   Tool Node      │───▶│  Memory Layer (3-tier)        │
               │   (LangGraph)    │    │  ┌─ SHARED ─────────────────┐ │
               └──────────────────┘    │  │ ChromaDB (facts/routines)│ │
                                       │  │ SQLite (routines/events) │ │
                                       │  └──────────────────────────┘ │
                                       │  ┌─ PER-CHANNEL ────────────┐ │
                                       │  │ session history (JSON)   │ │
                                       │  │ session summaries        │ │
                                       │  └──────────────────────────┘ │
                                       └───────────────────────────────┘

Background (AstakosScheduler — daemon thread)
    ├── job_check_reminders      every 20s
    ├── job_check_routines       every 60s    ← adaptive cooldown + anti-spam
    ├── job_proactive_scan       every 12h    ← watch_folder analysis
    ├── job_morning_fit_briefing every 1h     ← fires at 08:00, Google Fit daily summary
    └── run_analytics            nightly 03:00 ← LLM batch routine detection

Event Bus (core/event_bus.py)
    ├── routine_triggered  (routine_id, event, confidence, batch, channel)
    ├── routine_confirmed  (routine_id, event, channel)
    ├── routine_dismissed  (routine_id, event, channel)
    ├── session_ended      (channel, mood, summary)
    └── proactive_sent     (source, channel)
```

## 🗓 Routine Learning System

Astakos passively learns your habits from conversation and proactively reminds you.

**How it works:**
1. **Nightly Analytics** — every night at 03:00, the analytics engine reads the last 30 days of chat history from both Telegram and Web, sends them in batches to the LLM, and extracts recurring activities with their type and timing
2. **Pattern Detection** — activities are grouped by day/time bucket (±15 min), merged if similar, and promoted to "Everyday" if they appear 5+ days a week
3. **Threshold** — a routine is saved only if it appears 3+ times across 2+ different weeks
4. **Proactive Message** — when a routine is due in ~30 minutes, the LLM writes a natural message to send you. No templates.

**Routine Lifecycle:**
```
LEARNED → ACTIVE → TRIGGER_PENDING → CONFIRMED → ACTIVE
                                   → IGNORED   → ACTIVE (cooldown doubled)
                                   → DISMISSED → ACTIVE (Everyday) / DECAYED (weekly)
                                   → DECAYED   → ARCHIVED
```

**Adaptive Cooldown (Anti-Spam):**
- Default: 20h between notifications for the same routine
- 1st ignore → 40h | 2nd ignore → 72h | Confirm → reset to 20h
- Multiple routines at the same time → batched into one message

## 🔔 Telegram Commands

| Command | Effect |
|---|---|
| `/pause` | Pause reminder notifications |
| `/mute` | Mute all proactive messages |
| `/sleep N` | Sleep for N hours (pause everything) |
| `/resume` | Clear all overrides |
| `/status` | Show scheduler status, job health, queue size |
| `/voice` | Toggle voice reply mode ON/OFF (text in → voice out) |
| `/nutrition` | Analyze last photo as product label (food / cosmetic / household) |
| `/story [theme] \| [characters]` | Generate AI children's story + 3 illustrations |
| `/confirm <cmd>` | Execute a shell command with confirmation step |
| `/end` | Close session, run memory summarizer, clear working memory |
| `/help` | Show all commands with current voice mode status |

All state is persisted to `scheduler_state.json` and restored on restart.

## 🛠 Setup

### 1. Clone & Install

```bash
git clone https://github.com/alexneverland/Astakos-AI-Agent.git
cd Astakos-AI-Agent
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

### 2. Environment Variables

Create a `.env` file:

```env
# ── AI Engine ──────────────────────────────────────
GEMINI_API_KEY=your_gemini_api_key
PROJECT_ID=your_gcp_project_id
LOCATION=us-central1

# ── Telegram Bot ───────────────────────────────────
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

# ── Gmail (OAuth) ──────────────────────────────────
GMAIL_CREDENTIALS_FILE=credentials.json

# ── Optional Integrations ──────────────────────────
GOOGLE_PLACES_API_KEY=your_places_api_key
SPOTIPY_CLIENT_ID=your_spotify_id
SPOTIPY_CLIENT_SECRET=your_spotify_secret
GITHUB_TOKEN=your_github_token
VACUUM_IP=your_vacuum_ip
VACUUM_TOKEN=your_vacuum_token
```

### 3. Run

```bash
python main.py
# → Choose: [1] Web Server  [2] Telegram Bot  [3] Both

# Or directly:
python -m clients.telegram_bot       # Telegram only
uvicorn api.server:server --reload   # Web UI → http://localhost:8000

# Observability
open http://localhost:8000/debug/runtime
```
